## ❓ Troubleshooting
### Common Issues
- **Installer fails to start:** Ensure you have administrator privileges. Right-click the installer and select "Run as administrator."
- **Missing DLL errors:** Install the latest Visual C++ Redistributable from Microsoft's website.
- **Audio latency:** Adjust buffer size in your audio driver settings.
